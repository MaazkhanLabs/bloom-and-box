# Bloom & Box — Artisanal Florist & Curated Gift Hampers 🌸

A luxury e-commerce storefront for handcrafted floral bouquets, curated gourmet hampers, luxury keepsake boxes, and personalized gifts.

## ✨ Features

- **Editorial Luxury Design**: Crafted with an artisanal palette (Terracotta, Sage Botanical, Blush Petal, and Ecru Linen), soft pillowy shadows, debossed trays, and 24k foil stamp accents.
- **7 Complete Pages**:
  - `index.html`: Flagship storefront featuring Virtual Unboxing preview, Best Sellers, live Customization Atelier, and Concierge booking.
  - `bouquets.html`: Complete fresh flower catalog with category filtering (Roses, Mixed, Sunflowers, Lilies, Orchids, Preserved).
  - `hampers.html`: Curated gourmet and luxury hampers catalog.
  - `keepsakes.html`: Heirloom 24k gold roses, memory boxes, and crystal floral globes.
  - `custom.html`: Interactive 5-step custom gift builder with real-time reactive canvas proof and running price tally.
  - `occasions.html`: Occasion-based collection directory (Birthday, Anniversary, Wedding, Eid, Baby, Sympathy, etc.).
  - `blog.html`: *The Bloom Journal* — floral care tips, curation guides, and sustainability manifestos.
- **WhatsApp Direct Ordering & Payments**:
  - Live WhatsApp checkout with itemized order details, ribbon message, card vows, and delivery city.
  - Floating WhatsApp chat & order widget on all pages.
- **Responsive & Lightweight**: Built with Tailwind CSS CDN, Google Fonts (Noto Serif + Manrope), and Material Symbols. Zero heavy build tools required.

## 🚀 Running Locally

You can open any `.html` file directly in any modern web browser, or serve it using Python:

```bash
# Start local web server
python -m http.server 8080

# Visit in browser
http://localhost:8080
```

## 📱 Admin WhatsApp Configuration

To change the receiving WhatsApp phone number:
- Edit `DEFAULT_ADMIN_WHATSAPP` in `whatsapp.js`, or
- Click the ⚙️ settings button next to the floating WhatsApp icon on the live website.
